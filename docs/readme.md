

Run it with ./run.sh or ./release_run.sh (cargo run won’t work, it need to be run with wayland to have top_left position).







/src/io/ manage files writting/reading
/src/input/ manage user input
/src/ui/ manage rendering (without gpu)
/src/gpu/ manage gpu rendering
/src/domain/ manages fast note page/data
